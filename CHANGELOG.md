# Changelog

All notable changes to Frontier Mutators will be documented here.

## 0.1.0 - 2026-09-06

- Add float and integer frontier mutator nodes.
- Add fixed, uniform, and truncated-Gaussian sampling.
- Add hard bounds and quantisation.
- Add reroll, live-lock, deterministic restart, and effective-seed semantics.
- Add an on-node readout and one-click sampled-value promotion.
- Preserve full-width integer seeds without floating-point conversion.
